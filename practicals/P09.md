## Commands to understand and reproduce
These are teaching commands, not a script to run blindly on your main branch. Some examples need a fresh disposable branch or edits first; the evidence file records the exact operations actually performed.

```bash
git switch lab/rebase-demo
git rebase assignment/complete-practicals
# During a conflict: edit, git add <file>, then git rebase --continue.
# To cancel: git rebase --abort
git log --graph --oneline --all
```

## Conclusion
Rebase replays commits for linear history; merge preserves the branch topology. Do not rebase shared history casually.
