## Commands to understand and reproduce
These are teaching commands, not a script to run blindly on your main branch. Some examples need a fresh disposable branch or edits first; the evidence file records the exact operations actually performed.

```bash
# Use a disposable branch and clean worktree.
git reset --soft HEAD~1
git status
git reset --mixed HEAD
git status
# Revert an existing unwanted commit without rewriting public history:
git revert <commit-sha>
# Discard an unwanted, uncommitted tracked-file edit:
git restore <file>
```

## Conclusion
Reset moves a branch and optionally changes staging/worktree; revert creates an inverse commit; restore changes files.
