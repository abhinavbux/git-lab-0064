## Commands to understand and reproduce
These are teaching commands, not a script to run blindly on your main branch. Some examples need a fresh disposable branch or edits first; the evidence file records the exact operations actually performed.

```bash
git --version
git config --global user.name "Abhinav Bansal"
git config --global user.email "abhinavbansal676@gmail.com"
# Use an unused key filename; never overwrite an existing private key.
ssh-keygen -t ed25519 -C "abhinavbansal676@gmail.com" -f ~/.ssh/id_ed25519_lab_0064_new
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519_lab_0064_new
cat ~/.ssh/id_ed25519_lab_0064_new.pub
# Register ONLY the public key in GitHub Settings > SSH and GPG keys.
ssh -T git@github.com
```
