## Commands to understand and reproduce
These are teaching commands, not a script to run blindly on your main branch. Some examples need a fresh disposable branch or edits first; the evidence file records the exact operations actually performed.

```bash
git stash push -m "Work in progress"
git stash list
git stash pop
git tag -a lab-v1.0.0 -m "Git practical milestone"
git show lab-v1.0.0
# After checking that the tag name is unused on GitHub:
git push origin lab-v1.0.0
# GitHub > Releases > Draft a new release > select the tag.
```

## Conclusion
Stash temporarily shelves work; a tag names a commit; a GitHub release adds published notes/assets to a tag.
