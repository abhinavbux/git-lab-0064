## Aim
Demonstrate branch lifecycle and feature workflow.

## Evidence and result
Created a feature branch, committed a file, merged it with a merge commit, switched branches and deleted the merged feature branch.

[Actual output](../evidence/P05.txt)

## Commands to understand and reproduce
These are teaching commands, not a script to run blindly on your main branch. Some examples need a fresh disposable branch or edits first; the evidence file records the exact operations actually performed.

```bash
git switch -c feature/notes
# Edit and commit a new file.
git add .
git commit -m "Add feature notes"
git switch main
git merge --no-ff feature/notes
git branch -d feature/notes
```

## Conclusion
Branches isolate work and can be removed after integration.
