## Aim

## Evidence and result

[Actual output](../evidence/P06.txt)

## Commands to understand and reproduce
These are teaching commands, not a script to run blindly on your main branch. Some examples need a fresh disposable branch or edits first; the evidence file records the exact operations actually performed.

```bash
git merge lab/conflict-feature
# If both branches changed the same line, inspect conflict markers.
git status
git diff
# Edit the file to the final combined wording; remove all markers.
git add lab/lesson.txt
git commit -m "Resolve snapshot wording conflict"
git log --graph --oneline -6
```

## Conclusion
Conflicts require choosing and testing the intended combined content.
